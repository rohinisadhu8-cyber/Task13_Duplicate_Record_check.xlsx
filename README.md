Task 13: Duplicate Record Check

Objective

Identify duplicate records in a dataset and create a cleaned copy while preserving the original data.

Tools Used

- Microsoft Excel
- COUNTIFS
- Conditional Formatting
- Remove Duplicates

Process

1. Loaded the Sample Superstore dataset.
2. Created a separate working copy.
3. Checked records using selected key columns.
4. Identified duplicate records.
5. Removed verified duplicate rows from the working copy.
6. Documented the results and audit notes in a duplicate report.

Deliverables

- Excel workbook containing the original data, cleaned data, and duplicate report.

Outcome

The task demonstrates duplicate detection, data cleaning, and record verification while maintaining the original dataset for reference.
